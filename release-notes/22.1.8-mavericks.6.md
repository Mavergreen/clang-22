Catching an `__int128`, or any 16-byte-aligned class, by value no longer crashes on Mac OS X 10.9 to
10.13. Those systems' C++ runtime aligns a thrown object to 8 bytes, and clang read the caught copy as if
it were aligned to 16. Catching such a type by reference can still fault there, since code that uses the
reference assumes the type's alignment: catch it by value.

libcxx22's libraries are now marked safe for app extensions, as Apple's libc++ is, so an extension, or
a library linked for extensions, uses them on newer macOS without a linker warning.
