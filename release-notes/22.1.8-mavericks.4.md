clang22-cross now links against macOS 27's own SDK. That SDK's library stubs list a new
architecture, `arm64e.x1`, which LLVM 22.1.8's linker could not read, so any link against the host SDK
on macOS 27 failed with "could not load TAPI file ... unknown architecture". This release carries
upstream LLVM's fix (llvm/llvm-project#222721), in both toolchains.
